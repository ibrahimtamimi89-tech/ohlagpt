How this assistant works

  • Uses OHLA I-5 project documents (permits, RFIs, PCOs, contracts, submittals, specs) stored in a private AWS S3 bucket.
  • First tries to answer from project files. If the answer isn’t clear, it may fall back to general civil-construction knowledge.
  • Financial & cost-related questions require admin permission and may ask for a password.
