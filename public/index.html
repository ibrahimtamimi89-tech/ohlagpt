How this assistant works
  • Uses OHLA I-5 project documents: POTDs, permits, RFIs, PCOs, subcontractor contracts, project contract submittals, and Caltrans / Metro specs stored in a secure AWS S3 bucket.
  • First tries to answer from project files and summaries. If the answer isn’t clear, it may fall back to general civil-construction knowledge.
  • Some documents are read using OpenAI Vision. You may see an “extracted text preview” when a specific file is used.
  • Financial & cost-related questions require admin permission and may ask for a password.
This assistant is a helper only and does not replace official contract documents. Always verify critical information against signed plans, specs, and approved submittals.
