How this assistant works

  • • Uses OHLA I-5 project documents: permits, POTD, RFIs, PCOs, subcontractor contracts, project contract submittals, Caltrans & Metro specs.
  • • First tries to answer from project files. If the answer isn’t clear, it may fall back to general civil-construction knowledge.
  • • Some documents are read using AWS Textract. You may see an “extracted text preview” when a specific file is used.
  • • Financial & cost-related questions require admin permission and may ask for a password.
This assistant is a helper only and does not replace official contract documents. Always verify critical information against signed plans/specs and approved submittals.
